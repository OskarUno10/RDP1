Domain & cara memakai

Rencana: relay.projectkal.my.id:PORT_PUBLIK. Buat DNS-only record ke IP publik relay setelah forwarding penjual terverifikasi. Aplikasi ini tidak mengubah DNS atau memasang Tailscale otomatis.

Batas enam jam berlaku untuk sesi relay manual ini, bukan timer run GitHub. Belum ada sinkronisasi otomatis saat run GitHub selesai. Tekan Stop jika runner selesai lebih awal. Tutup konsol aplikasi untuk menghentikan seluruh relay.

RdpFree · KallAncrit · Jangan forward port panel 8787 ke internet. Tidak menyimpan password RDP. Relay tidak menambahkan enkripsi: gunakan Tailscale/WireGuard untuk jalur privat dan RDP dengan NLA/TLS.
